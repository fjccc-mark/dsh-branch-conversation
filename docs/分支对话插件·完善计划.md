## 3. API 取证结论（C1 / C7 / C8）

### 3.1 用哪些 API（决定，非推测）

| 用途 | 选用 | 理由 |
| --- | --- | --- |
| 建子会话（**不继承上下文**） | **`ctx.agents.create({ sessionId, meta: { cwd, parentSession, isSeeded:false, delegationDepth:0, agentPreset }, agentOptions, setup })`**，**不给 seed**（2026-10-17 修正：原定 `ctx.sessions.create` **不落盘**——官方原话 "a session published outside that lifecycle persists nothing"，见进度快照 §4.6 / 缺陷 27） | `seed` 才是复制历史的入口；`meta` 只写血缘与 preset。**只有 Agent 工厂那条链才挂持久化写入器**，走它才会出现在会话列表里。这是 B3 的正解 |
| 会话列表/搜索 | `sessionController.list()` / `search()` | 冷读、不激活 Agent；带 `parentSessionId`、`blank`、`running`、`cwd` |
| 节点（turn）枚举 | `sessionController.page()`（按消息对齐）+ `follow()` | 轴线按 turn 渲染，无需读全量日志；`turn/end` 即节点边界 |
| **子智能体排除** | 以 `SessionSummary.origin === 'subagent'` 与会话头 `origin` 为准，整条排除 | 第 7 条裁决：模型自己调的智能体不建节点 |
| 会话切换 | `ctx.uiWorkspace.openSession(sessionId)` | 官方导航面（本机 git-graph 插件中已实测使用） |
| 人设/模型继承 | `SessionHeader.agentPreset` → 建会话时同名传入；模型用 `sessionController.selectModel()` | preset 决定工具集与提示词，是"人设/权限"的真正载体 |
| 侧边栏可切换页与文件预览 | 官方侧边栏页签接缝 + 官方文件预览入口 | 第 6/B5 条裁决要求；具体接缝名 M0 核实 |
| 持久化 | 插件自有 JSON + 原子写 + **每树一把锁** | B2 要求独立于 DSH；`dsh-atomic-write` 仅作参考实现 |

**明确不用**：`sessionController.fork()`（会复制前缀历史，与 B3 冲突）；直接读写 `session.v4.jsonl.zstd`（D2 风险）；`ctx.subagents` 建出的会话**不作为树节点**（第 7 条裁决：模型自己调的智能体不算；该服务只留作 v2「让模型自己开分支」的扩展位）。

### 3.2 会话血缘的事实依据

- `SessionHeader` 含 `parentSession` / `seedLength` / `origin` / `delegationDepth` / `agentPreset`；
- `SessionSummary` 暴露 `parentSessionId` / `origin`；
- **`seedLength` 的官方语义就是"继承了多少前缀事件"** → 子会话 `seedLength = 0`、血缘非空，语义自洽；
- 已装的 `dsh-session-archive` **正是靠 `parentSessionId` 组父子树**，说明这是既有生态的公共约定，本插件沿用它不会成为孤岛。

### 3.3 DSH 插件对"失败与恢复"的既有做法（C7 总结）

| 场景 | 生态做法（可照抄） |
| --- | --- |
| 依赖的 API/slot 不存在 | **形状探测 + 功能关闭 + 打印诊断**，不硬崩（git-graph 在 SDK 删槽位后自动回退到另一槽位） |
| 持久化写入 | 同目录临时文件 + fsync + **原子发布**；不以 `rename` 静默覆盖；no-clobber 用 `link()`+`unlink()` |
| 崩溃残留 | 日志类要处理 **torn tail**；结构性文档要能判"坏"并降级只读 |
| 资源释放 | 一切注册（路由/slot/timer/watcher/React root）挂 `ctx.effect` disposer，HMR 与卸载都靠它 |
| 卸载 | 先注销入口 → 等在途工作 → 关资源；**不删用户数据目录**（重装可续用） |
| 初始化失败 | 让 fiber **失败并报告**，不吞异常 |
| 并发创建 | 显式串行化 + 幂等键 |

→ 落地映射：树文档原子写 + **每棵树一个写队列**（异树并行）；slot/host 路由全部走 `ctx.effect`；探测失败降级；卸载不删树文档。

## 4. 保守设计清单（D 的实现方式）

1. **只读优先**：v1 的写动作只有——建子会话、建文件节点、折叠状态、父会话被删后的拆树升根；重命名/移动/删除节点只留接口。
2. **不碰 DSH 数据**：不写会话日志、不改会话头、不做会话删除（留给 archive）。
3. **不复制文件**：文件节点只记路径。
4. **失败即降级**：任何 SDK 面缺失 → 关功能 + 诊断，页面可用。
5. **无网络无遥测**：纯本地。
6. **可撤销**：写动作先写临时文件，失败保留旧文档；**每棵树一把锁**（锁键 = `treeId`，异树并行，升根双锁按固定顺序避免死锁）；建会话成功但写树失败 → 明确提示，不静默留半成品。
7. **版本门**：`>= 0.2.0-rc.2`；文档带 `schema`，高版本只读。

### 5.5.1 定义（可判定的口径）

| # | 要求 | 可判定口径 | 反例（做不到就是不合格） |
| --- | --- | --- | --- |
| F-1 | **在对话的侧边栏打开** | 「分支对话」行出现在**官方侧边栏的面板行列表**里，与官方面板行（对话 / 轨迹 / 文件等）**同栏共存**，鼠标/键盘可切换 | 只能通过命令、URL 参数、独立入口进入 |
| F-2 | **是"可切换页"，不是独立窗口** | 点该行后**中央列**切换为本插件页面；浏览器地址栏不跳转、不开新窗口/新标签 | 另开窗口、独立路由页、需要开终端 |
| F-3 | **图形化 = 节点框 + 连线**（Visio 式） | ① 每个节点是**有边框的矩形框**（可见 border、固定尺寸）；② 框之间**有画出来的连线**（SVG `path`/`line` 或 canvas 描边），端点贴在框边缘；③ 位置是**二维坐标**（同级节点成行，不是单列堆叠）；④ 同一会话相邻轮次的**轴线也看得见** | 一行文字、缩进列表、只有 `│├└─` 字符、只有空白缩进 |
| F-4 | 折叠是**图形行为** | 折叠后后代与其连线一并消失，**剩余节点重新排布**，连线端点仍贴在框上 | 折叠只改文字、线不动或残留在原位 |

### 5.5.5 M6 实际落地（2026-10-16，与上面的计划逐条对应）

| 项 | 决定 | 为什么 |
| --- | --- | --- |
| 布局方向 | **主轴向下、分支向右**：主轴（同会话相邻轮次）同列向下叠（`y` 每轮 + `NODE_H+ROW_GAP`），分支（跨会话）向右每层 + `NODE_W+LEVEL_GAP`；`NODE_W=208`、`NODE_H=62`、`LEVEL_GAP=56`、`ROW_GAP=18`、`PADDING=24` | **主轴纵向**：真机上同会话轮次是平铺的兄弟，纵向串接让 12 轮仍只占**一列宽**（旧版向右会把画布撑到 3000px+）；**分支向右**：中央列宽小于高，分支只加"高"更好滚 |
| 同一父节点的多个分支 | 都从**同一列**起算、彼此**上下叠**，且排在**父框下方**（`父框下缘 + ROW_GAP`） | 分支互不往右推（否则每多一个子对话就多一整列）；排在父框下方才不会"父框压自己的分支" |
| 纵向排布 | **子树外接盒递归**：先算子节点，父框按"主轴列 / 分支列"两块拼起来，最后按**连通块**归一化并自上而下叠放 | 抽掉"槽位制"后主轴与分支可以各走各的轴；连通块分开摆才能让互不相连的多根不重叠 |
| 节点渲染 | **绝对定位 DOM 框**（固定 `208×62`） | 框仍是真按钮（可 Tab、可 `aria-*`、中文可 `-webkit-line-clamp` 截断）；**固定尺寸**才谈得上"框不重叠"的可判定断言 |
| 连线渲染 | 一层绝对定位 `<svg>`（`pointer-events:none`），与框共用同一套画布坐标 | 线不拦点击；`svg` 的 `width/height/viewBox` 都取画布尺寸，整层随 `scale()` 一起缩放，线宽与框自动对齐 |
| 折线走向 | **主轴**：父下缘中点 → 子上缘中点（一条竖线，走两框之间的空隙）；**分支**：父右缘中点 → 竖线（按第几个子错开 `±14px` 车道）→ 子左缘中点 | 主轴两端同列，竖线走中间会**穿过两个框**（F-8 反例）；分支错开竖线才不会穿过中间的子框 |
| 画哪些边 | **只画排布期真正建立的连接**（含显示层合成的主轴，排布时记进 `links`），事后不拿 `children` 重算 | 数据损坏（`a→b→a` 环、`x→x` 自环）时递归靠 `seen` 只排一次，但"事后重算"会把环上每条都画出来（甚至画出 `b→a`、自环）。**画出来的线必须与排布时的连接严格相等** |
| 主轴 vs 分支 | `axis`：合成的主轴边恒为 `main`；其余按"子节点.sessionId === 父节点.sessionId"判。主轴**实线**、分支**虚线** | B10 的"轴线"= 同一会话相邻轮次连成的线，要在视觉上能与"岔出去的子对话"分开 |
| 主轴优先于分支 | 主轴下游即使**同时**出现在 `children` 里，也必须走"向下"那条路 | 否则主轴会横着摆、边还用分支折线，端点自然对不上（实测暴露） |
| 折叠 | 折叠节点的后代**不进 `nodes` 也不进 `edges`**；**主轴下游整条链也一起隐藏**（它是这一轮的延续） | F-4 要的是"图形行为"；下游轮次在树文档里不是它的孩子（合成链），不单独处理就会"越级上前" |
| 多根 | 互不相连的根各自成块、自上而下叠放 | 同一文档里可能有多个独立根（真机数据形状），只做一次平移会让它们落在同一格 |
| 窄屏 | 画布**双向滚动**；首次进画布按容器宽自动缩放（**下限 30%**，再小就看不清字了） | F-5 的新口径：退化的是字号与显示量，**不是图形本身** |
| 防退化 | `layout-check` 断言画布内 `│├└─` 轨道字符数 `=== 0` | 防止有人把形态退回成缩进列表（M2 那版） |
